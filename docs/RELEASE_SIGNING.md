# توقيع إصدارات وصل شات

سجل مرجعي لمفاتيح توقيع إصدارات أندرويد. ملف المخزن نفسه لا يُحفظ في
المستودع أبداً — يأتي من سرّ `KEYSTORE_BASE64` في GitHub Actions عند البناء.

## مفتاح الإصدار الحالي (2026-11)

- **الاسم المستعار (alias):** `wasl`
- **الخوارزمية:** RSA 4096
- **صالح حتى:** 18 نوفمبر 2056
- **بصمة الشهادة SHA-256:**
  `AC:66:7C:94:D4:4E:D6:0C:85:13:44:A1:5D:18:8F:A8:B3:38:94:DD:D8:5C:F2:54:45:06:7C:77:68:2A:F0:20`
- **التمييز (DN):** CN=Wasl Chat, OU=Engineering, O=CTO-DRS, C=SA
- **أُنشئ:** 26 نوفمبر 2026 (استبدال تأسيسي — لم يكن هناك مفتاح إصدار
  قابل للاسترجاع قبله؛ أي تحديث فوق تثبيت موقّع بمفتاح أقدم يتطلب
  إعادة تثبيت).

## أماكن الحفظ

- كلمة مرور المخزن والمفتاح (واحدة مشتركة): خزنة المستخدم، مدخل
  «Wasl release keystore password 2026-11».
- أسرار GitHub Actions على هذا المستودع الخاص: `KEYSTORE_BASE64` و
  `KEYSTORE_PASSWORD` (يستخدمهما `.github/workflows/build-apk.yml`).
- نسخة المخزن الاحتياطية الخام: تُدار خارج المستودع (الخزنة + الأسرار).

## للتحقق من توقيع APK

```bash
apksigner verify --print-certs wasl_chat.apk | grep SHA-256
```

يجب أن تطابق البصمة أعلاه.
